# Security Policy

## Supported Versions

This project is a proof of concept and does not maintain long-term supported
releases. Security fixes are applied to the latest commit on the `main`
branch.

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please report it
privately using [GitHub's private vulnerability reporting](https://github.com/darccio/knobs/security/advisories/new)
instead of opening a public issue.

Please include as much detail as possible:

- A description of the vulnerability and its potential impact
- Steps to reproduce the issue
- Any relevant logs, code, or configuration

You should receive an initial response within a few days. If the
vulnerability is confirmed, we will work on a fix and coordinate disclosure
with you.
